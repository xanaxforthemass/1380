1. In one sentence, why put name, jersey, and points in one struct instead of three separate variables?
    Because it makes it easier to see that each name, jersey, and points are attached to a particular player instead of trying to manage 15 different vairables.
2. What does p->jersey mean, and how is it different from p.jersey?
    p->jersey is how you refer to the jersey member in the struct when p is a pointer. This is different from p.jersey, which is how you would manipulate the member without a direct pointer.
3. Why must init_player leave room for '\0' when copying into name[32]?
    Because without a null terminator, the char array is not a string, and this can cause issues with functions that search for the null terminator. They could run for quite
    some time and the behavior is undefined.

6. In one or two sentences: what is a coding agent, and how is it different from plain autocomplete that only suggests the next few tokens?
    A coding agent is an AI model with access to tools that can read and write files, search the web, and invoke shell commands. This is different from autocomplete because it can use tools,
    accomplishing tasks by examining files, editing code, and running texts.

    Other than just explaining the struct I want it to initialize, I would guide it by saying "ensure you check the pointer for NULL, limit the char array to 31 characters + '\0' and to set NAME to an empty string if NULL.

    Since agents can make mistakes, it makes sense to double check what files you allow them to edit or what shell commands you allow them to run.
