Part 1 questions:
What does a pointer store? How is that different from storing the price itself?
    A pointer stores an address in memory. This is different, as it references the place that the value was stored, rather than the direct value.
After int *tag = &latte;, what do tag, *tag, and &latte each mean?
    *tag is the value at the address stored in tag. tag is the address itself, and &latte is the address where latte is stored.
Why is it undefined behavior to dereference an uninitialized pointer? What should you initialize a pointer to if it does not yet have a target?
    Because an uninitialized pointer will point to some random point in memory. You should initialize it to NULL. Then, at least, you can check if the pointer != NULL.

Part 2 questions:
Why does retarget take int ** instead of int *?
    Because we intend to change the address of the pointer, not the value that it points to.
Why can print_price take const int * while set_price cannot?
    Because print_price does not change the value that the pointer points to. set_price does, and that reassignment would not work with a constant.
In your array demo, why does p + 1 not add one byte?
    Because p was declared as an int pointer, so each + 1 moves the pointer forward by the size of an int (4 bytes in this case).
