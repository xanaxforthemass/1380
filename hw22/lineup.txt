Part A questions:
Why prefer strncpy + a forced '\0' over plain strcpy when the destination has a fixed size?
    Knowing how many characters to copy can help prevent overflow, as you  can limit how many characters get moved to the new string. The forced '\0' ensures that the 
    destination string is properly terminated, even if the source was too long to fit.
Before calling strncat, what two numbers do you need so you know how many characters still fit?
    You need to know the array's current capacity, and the current string length.
What does strcmp return when the two strings are equal?
    When two strings are equal, strcmp returns 0.

Part B questions:
If strstr finds a match, why is the return value a pointer into the original string rather than a new copy?
    This is because it would be somewhat pointless to copy the pointer. The matching text exists in the original array, and the return value can be used to perform pointer arithmetic, 
    or to find elements immediately following the matching text.
After safe_join, how do you know dest is still a valid C string?
    I know it is still a valid C string because I made sure there was room in the destination array to append the extra portion and strncat will add the null terminator for me.
