Part A questions:

Why must a C string end with '\0'? What can go wrong if that byte is missing?
    It must end so different functions in C know where to stop when processing strings Without it, even functions like printf would keep reading memory
    even past the array bounds, which is undefined behavior.
Why is char *p = "Wolves"; p[0] = 'w'; unsafe, while changing char name[] = "Wolves"; is allowed?
    because p is a pointer to a string literal, while name is an array. You can change the value of a particular index of an array, 
    but modifying a string literal in C is undefined behavior.
If dest has room for 5 characters including '\0', what should team_copy store when src is "Wolves"?
    It should truncate to {W, o, l, v, \0} or "Wolv"

Part C questions:

What a dependency is (give one C example and one Python example from the reading).
    A dependency is a set of files, a library, or a whole program that another program or library needs in order to function. An example in C would be stdio.h, which we include in nearly every C file.
    An example in Python would be certifi, which is a dependency of the requests library.
Why a project should use its own environment instead of changing the Python that came with the operating system.
    This helps to avoid any conflicts with other dependencies in the native OS (or other projects) and provides much more control as to which dependencies are included when the program runs.
