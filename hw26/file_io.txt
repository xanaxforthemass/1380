Part A questions:
1. What does fopen return on failure, and what should you do before using the FILE *?
    fopen returns NULL on failure, and you should check for this before using the FILE pointer.
2. Name two common file modes and when you would use each.
    "r", when I would want to read from a file, and "w", when I want to write to a file.
3. Why should every successful fopen have a matching fclose on every exit path?
    To prevent resource leaks or data corruption.

Part B Questions:
4. When is fgets a better choice than fscanf for reading a whole line?
    Whenever you aren't sure about the structure of the lines you will be reading, or if the lines are not standardized.
5. In one sentence, how does binary fwrite of a struct differ from writing the same fields as text with fprintf?
    binary fwrite writes the struct in binary, whereas fprintf would convert the fields to text before writing them to a file.
